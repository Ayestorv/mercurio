Run: 2026-10-12 (second fill). Builds on [2026-10-03](2026-10-03-competitor-map.md): every row from that run is carried forward with its source, and the "Us" column is re-read against `main` at `ebcbb46d`. New this run: Whip (an Android Herdr client), Termius (its mobile gesture docs), and Moshi's Android listing and gesture docs, all fetched on 2026-10-12. Star counts, user counts and engagement are deliberately left out. `?` means no source was read for that cell, not that the feature is missing.

## Product

- Name: Mercurio (renamed from Logos, PR #49)
- Flagship: a native Android control surface for one operator's agent fleet. It speaks into, reads and moves between many Claude Code, Codex and Grok sessions running in Herdr on the operator's machines, over plain SSH on Tailscale. A ConnectBot fork, so the full terminal stays underneath.
- Our surfaces (main `ebcbb46d`):
  - Console: two-row compose bar with dictation and a swipe-up tray (#61, #78), Herdr panel with numbered tab keys and editable keys (#70, #91, #93), Herdr swipes for tabs, panes and workspaces (#92, #118, #121), taps as mouse clicks when the program asks for the mouse (#117), one Needs you key (#120)
  - Herd: Herd home (#54), every Herdr session on the host (#112), Jump to any tab (#114), Agents board across sessions with the ask on needs-you cards (#116, #142)
  - Chat View for the focused Herdr pane, ask pinned on top, labelled turns (#111, #140, #141)
  - Notifications from Herdr status (#57), Approve and Deny from a notification without an open session (#87, #96), UnifiedPush from the project's own host watcher (#89, #95, #97)
  - Devtools: diff viewer, repo tree, in-app preview of a host dev server (#110, #113, #115)
  - Machines list from `tailscale status --json` through a connected host; saved hosts above it (#139)
  - Usage log, wish list and error inbox (#56)
  - Debug build `solutions.ormus.logos.debug` on the emulator named in `pantry/README.md`
